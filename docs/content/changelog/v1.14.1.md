### Performance

- **Binds are returned directly**: The bind constructors no longer wrap the concrete bind in a delegating struct, so
  every retrieval saves an interface hop.

- **Storage maps allocated on first write**: A storage that never receives a bind no longer allocates its map. Reading a
  nil map is safe in Go, so the allocation waits for the write that needs it.

- **Struct field alignment**: `betteralign` reordered the internal structs, shrinking the injector and bind types.

No public API changed in this release.
