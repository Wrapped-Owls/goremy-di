### Added

- **`Config.MultiBinding`**: Enables the `GetAll` family on its own, without turning on duck typing. Until now the only
  way to list every bind under a tag was `DuckTypeElements`, which also made every `Get` scan the registry.

- **`RegisterAs[Iface, Impl]`**: Registers an implementation under an interface key explicitly, so the interface can be
  resolved without relying on the duck typing scan.

- **`Config.TraceResolution`**: Opt-in flag that makes a failed lookup carry the dependency path that led to it
  (`A -> B -> C`). It costs one allocation per failed `Get` and nothing on success.

- **`DependencyResolutionError` and `ResolutionPathEntry`**: The error type that exposes that path, plus the
  `ErrDependencyResolution` sentinel for `errors.Is`.

- **`injopts.ResolveConfOption`**: Resolution options now live in their own bitmask, with `ResolveOptNone`,
  `ResolveOptDuckTyping`, `ResolveOptTracePath` and `ResolveOptIsolated`, and an `Is` method to test them.

### Changed

- **Resolve options split out of cache options**: `injopts.CacheConfOption` no longer carries resolution concerns. The
  split is additive, so no existing constant changed meaning.

### Fixed

- **Register-time cycles in singleton generation**: A `Singleton` or `Instance` bind is resolved while it registers, and
  a chain that circled back into the key being registered reported an unregistered element instead of the cycle.
