### Added

- **`Config.ScopeName`**: Labels an injector scope for diagnostics. Anonymous scopes stay the default and cost nothing.

- **`Config.Isolated`**: Stops a lookup miss from falling back to `ParentInjector`, so the scope resolves and lists only
  the binds it owns.
