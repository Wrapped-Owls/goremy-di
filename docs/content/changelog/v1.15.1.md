### Fixed

- **A failed build no longer poisons the `LazySingleton` cache**: When the binder returned an error, the zero value was
  stored anyway, and every later `Get` returned `(zero, nil)` in silence. The cache is now written only on success, so a
  failing binder is retried and keeps reporting its error.

- **The singleton cache is read atomically in every build**: The cache used to be guarded by a lock only under the
  `race` build tag, which meant the race detector exercised a variant that was already safe and never saw the
  unsynchronized one that shipped. Both builds now share a single `atomic.Pointer`, so the detector watches the real
  code.

- **Every injector constructor honours `Config.ParentInjector`**: All the constructors now build their base through one
  shared path, instead of each one deciding whether to pass the parent along.

No public API changed in this release.

### Repository

- **`remychef`** landed as a separate module, with its own version line. It is a lifecycle layer on top of remy
  (ordered startup and shutdown, health checks, operating system signals) and requires **remy v1.15.0 or newer**,
  because it consumes `remy.Tag` and `remy.Binder`.
