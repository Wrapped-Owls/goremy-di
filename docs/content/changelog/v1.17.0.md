### Added

- **`Decorate[T]` and `Decorator[T]`**: Wraps a bind so a decorator runs over the value it produces, without touching
  the registration the bind came from. This is the classic decorator: auditing, tracing or retry added around a
  dependency that does not know about it.

  The decorator receives the `DependencyRetriever`, so the wrapper can be built from other registered dependencies:

  ```go
  func auditLanguage(retriever remy.DependencyRetriever, language Language) (Language, error) {
      audit, err := remy.Get[*AuditLog](retriever)
      if err != nil {
          return nil, err
      }

      return AuditedLanguage{Inner: language, Audit: audit}, nil
  }

  remy.Register(injector, remy.Decorate[Language](languageBind(), auditLanguage))
  ```

  The decoration is folded into the bind's own generator rather than layered on top of it, so it shares whatever
  lifecycle the bind already had: a `Factory` decorates every value it builds, while an `Instance`, a `Singleton` and a
  `LazySingleton` are each decorated exactly once. Binds nobody decorates pay nothing.
