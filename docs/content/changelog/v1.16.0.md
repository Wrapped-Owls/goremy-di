### Added

- **`NewGraphInjector`**: Returns an `Injector` together with a `Graph` view of what it recorded. Every resolution that
  passes through it becomes an edge, so the dependency wiring can be read back instead of guessed. It suits debugging
  and tests, never a hot path.

- **`Graph`, `GraphNode`, `GraphEdge`, `FailedNode`**: The read side of that recording. `Graph.Edges` lists what was
  requested by what, and `Graph.ResolveAll` builds every registered bind, returning the ones that failed with the reason
  each gave.

- **`NewCycleDetector`**: Detects a dependency cycle at runtime without recording any edge, for the common case where
  the graph itself is not wanted.

- **`utils.Satisfies`**: Reports whether a value can stand in for `T`, returning it already typed.

### Changed

- **`NewCycleDetectorInjector` is deprecated** in favour of `NewCycleDetector`, or `NewGraphInjector` when the recorded
  graph is also wanted. It keeps working and now returns the `Injector` interface instead of an unexported concrete
  type, which callers could not name anyway.

### Fixed

- **Cycle detection survives a temporary scope**: A cycle that closed inside a `GetWith` or `GetWithPairs` binder, or
  across a `SubInjector` created mid-resolution, escaped the detector entirely and recursed until the stack died.
  A temporary scope now carries the path walked so far, so the cycle is reported instead of hanging.
