### Added

- **`Tag`**: Tags are now a defined type instead of a bare `string`, so a value meant as a tag cannot be passed where a
  plain string is expected, and the other way around.

- **`NewTag[Scope]`**: Builds a tag namespaced by an anchor type, the way `context.WithValue` keys work: a package that
  cannot name the anchor cannot forge the tag. The suffix is an opaque per-process id, so it must not be hardcoded or
  persisted.

- **`Binder[T]`**: The bind builder function is now exported from `remy`, so consumers can name it instead of writing
  the signature out at every call site.

### Changed

- **Every tag parameter takes `Tag` instead of `string`**. This affects `Get`, `MustGet`, `MaybeGet`, the `GetAll` and
  `GetWith` families, `Register` and its variants, `Override`, `NewBindEntryTagged`, and the `With*` module registers.

  Untyped string constants still satisfy `Tag`, so a call written as a literal keeps compiling:

  ```go
  remy.RegisterInstance(injector, value, "database")   // still valid
  ```

  A `string` variable needs an explicit conversion:

  ```go
  tag := loadTagFromConfig()
  remy.RegisterInstance(injector, value, remy.Tag(tag))
  ```

- **`Binder` is declared in `remy`**: The bind constructors take `remy.Binder[T]` instead of the internal type. Function
  literals are unaffected, since they were never of a named type.
